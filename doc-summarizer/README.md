# Doc Summarizer\n\nA small Python CLI that reads a document (txt or pdf) and summarizes it into concise bullet points using a HuggingFace summarization model.\n\nUsage:\n\n1. Create a virtual environment and install dependencies:\n\n```bash\npython -m venv venv\nvenv\\Scripts\\activate  # Windows\npip install -r requirements.txt\n```\n\n2. Run the summarizer:\n\n```bash\npython main.py path/to/document.pdf\n```\n\nNotes:\n- For long documents the script chunks the text and summarizes chunks individually.\n- Model can be changed with --model flag.\n\nTODO:\n- Add token-aware chunking (use tokenizer from the chosen model).\n- Support DOCX and HTML input.\n- Add caching for model and summaries.\n
